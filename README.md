# Deskripsi Jabatan BRI - Regional Office Yogyakarta dan Unit Kerja

## Struktur folder
```
├── index.html          -> Halaman utama
├── style.css             -> Styling
├── script.js              -> Logika (menu, buka detail, dsb)
├── divisions_data.js      -> Data divisi
```

## Cara kerja
1. **Menu hamburger (☰)** di pojok kiri atas membuka daftar isi 13 divisi.
   Klik salah satu nama akan otomatis scroll ke card divisi tersebut.
2. Tiap card divisi punya tombol **DOWNLOAD** yang mengunduh paket file
   lengkap divisi itu.
3. Tiap poin jabatan (misal "REGIONAL SME BANKING HEAD") kalau diklik akan
   membuka halaman detail yang menampilkan preview detail rincian pekerjaan jabatan tersebut.
   Ada tombol **Kembali** untuk balik ke tampilan awal dan **download** untuk mendownload hanya isi bagian itu saja.
4. Anda dapat melihat Key Performance Index pada bagian KPI dan mendownloadnya.
